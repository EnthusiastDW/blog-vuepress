## 空安全

必须明确变量是否可以为null，以？表示可以为null

使用前必须初始化，可以为null的类型初始值为null

将运行时错误转换为了编译期错误。
```dart
String? name  // Nullable type. Can be `null` or string.
String name   // Non-nullable type. Cannot be `null` but can be string.
```

非空变量使用前必须初始化

延迟初始化，
```dart
// This is the program's only call to readThermometer().
late String temperature = readThermometer(); // Lazily initialized. 只有在用到的时候才会调用初始化方法
```

::: warning
如果你没有初始化一个 `late` 变量，那么当变量被使用时会发生运行时错误。
:::

::: tip
[实例变量](https://dart.cn/language/classes#instance-variables) 可以是 `final` 但不能是 `const`。
:::

```dart
final name = 'Bob'; // Without a type annotation 
final String nickname = 'Bobby';
const bar = 1000000; // Unit of pressure (dynes/cm2)
const double atm = 1.01325 * bar; // Standard atmosphere

var foo = const []; 
final bar = const []; 
const baz = []; // Equivalent to `const []`
foo = [1, 2, 3]; // Was const []

```
虽然 `final` 对象不能被修改，但它的字段可能可以被更改。相比之下，`const` 对象及其字段不能被更改：它们是 **不可变的**。
